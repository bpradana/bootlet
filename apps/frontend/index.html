Network

bootlet runs entirely in your browser, and browsers can't open network connections on their own. A small relay program on your computer opens them for the guest, so apk add, curl and git work.

  1. Download the relay:
  2. Run it. macOS and Linux: chmod +x bootlet-relay-*, then ./bootlet-relay-*. Windows: double-click it.
  3. Open http://localhost:8089, which works in every browser. Or connect this page below: Chrome and Edge ask once to allow access to this device; Safari doesn't allow it.
